# Brand assets (ACID2Reaper)

## Logo

`acid2reaper_logo.png` — psychedelic “acid” inspired artwork with a stylized **scythe** motif (nod to REAPER’s grim‑reaper branding), suitable for marketing and app icons.

`acid2reaper.icns` and `acid2reaper.ico` are generated multi-resolution app
icons used directly by `packaging/pyinstaller.spec` on macOS and Windows.

Regenerate both derived files from `acid2reaper_logo.png` whenever the source
artwork changes, preserving standard sizes from 16 through 1024 pixels.
